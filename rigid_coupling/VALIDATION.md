## 触底上浮诊断及效果辅助

对原始耦合进行静水对照：相同密度比 0.5、水量与粒子种子，改变初始底部缝隙。贴底（0）和半格缝隙（0.015625）在 2 秒时均回到池底；1.5 格缝隙（0.046875）则从质心 0.230625 上升至 0.294390，最低表面离底 0.105206。对应初始底面下方水粒子数为 0、28、96，2 秒时分别为 6、20、225。这支持底面附近水层及压力反馈分辨不足的判断，而非池壁代码禁止正向速度。实验用相同静水初态隔离底部因素，不是直接从注水过程取样；详情见 `results/rigid_coupling/liftoff_diagnosis.json` 和同目录脚本 `diagnose_liftoff.py`。

经用户允许，为展示效果添加独立 `buoyancy.py`。`corner_inflow` 命令行默认开启 `buoyancy_assist`，仅作用于双向组；`--no-buoyancy-assist` 恢复原始行为，`buoyancy_pool` 默认关闭。辅助由已落入下半容器的水体积估计平均水位，采用旋转方块内 4³ 点的平滑体积积分计算浸没体积。它用重力、阿基米德浮力与竖直阻尼推进质心竖直速度，替换当前步已有的竖直流体反馈，避免重复叠加。水平方向和角速度仍由原求解器计算。

这项辅助假设底面可被水润湿，也没有向水施加等量反冲量。它是可开关的展示近似，不是 PBMPM 原推导的浮力精度或动量守恒证据。界面明确显示辅助状态，CSV 保存 `assist_water_level`、`body0_assist_submerged_fraction` 和 `body0_assist_delta_vy`。

默认注水、相同 11,718 个水粒子下，辅助双向组在 2.5 秒时离底 0.02687；10 秒质心高度 0.368720、最低表面离底 0.119618、竖直速度 0.000177。模型估计浸没比例为 0.499975，接近密度比 0.5，但这是该辅助模型的平衡结果。单向组仍停留于池底。此轮每 0.5 秒采样中的最大流固穿透深度约 2.38e−4，最后一次为 8.78e−6；均小于一格但不为零。结果目录为 `results/rigid_coupling/20261025-173800-224339+0800_corner_inflow/`，所有保存状态有限。

新增 `test_buoyancy_assist.py` 五项测试通过：干燥时仅重力、完全浸没时的解析加速度、重轻密度响应、替换而非重复叠加竖直反馈、重置和单向隔离，以及入口开关。CLI 五项和 viewer 六项回归通过。

密度比改为 2 的辅助双向组在 6 秒时仍在池底（质心 0.183775、最低表面距池底 5.90e−9），没有被无条件抬起。结果为 `20261025-174142-536827+0800_corner_inflow/`。辅助模式双面板图像另存为 `assisted_inflow_6s.png`。

## 角落注水（最新默认场景）

默认入口现为 `corner_inflow`，原 `buoyancy_pool` 保留。网格 32³、PPC 2 时，容器内部尺寸为 0.8125³，目标释放体积为 0.1787923177，等于容器内部体积的三分之一。初始只有 512 个刚体粒子启用，11,718 个水粒子按物理时间逐步释放，在 4 秒时全部启用并停止注水。两种耦合模式共用相同入口坐标、种子、释放时序和总水量。

GPU 运行到 8 秒通过，结果目录为 `results/rigid_coupling/20261025-172401-308381+0800_corner_inflow/`。0、2、4、8 秒时，两组水粒子数量均分别为 0、5,859、11,718、11,718；4–8 秒的累计体积比例保持 0.333333343（浮点精度）。采样状态中粒子超出容器的距离均为 0。随后使用避免每步主机字段写入的释放核进行了 6 秒批处理及图像检查，数据为 `inflow_verification.json`，图像为 `inflow_1s.png` 和 `inflow_6s.png`，位于同一结果根目录。

新增 `test_corner_inflow.py` 三项 CPU debug 测试通过：累计体积上限、单双向初态与释放计划一致、改变 PPC 保持总水量、未释放粒子不进入网格或画面、暂停不释放、批处理和单步时序一致、重置复现、输出正确保存 active_count。显示半径继续使用此前缩小一半的设置。

## 静水池单双向对比（保留场景）

本次水池实验使用 NVIDIA GeForce RTX 5060 Ti、CUDA，网格 32³，步长 0.002，每步 5 次迭代，重力 −9.8，黏性参数 0。刚体与水的密度比为 0.5。默认每侧 24,794 个随机水粒子和 512 个刚体粒子，目标 PPC 从 4 降为 2，实际 PPC 为 2.1192。水的静止体积为 0.35704635，改变采样数不改变总水量。

```powershell
.\.venv\Scripts\python.exe -m rigid_coupling --scene buoyancy_pool --arch cuda --duration 10 --sample-every 200
.\.venv\Scripts\python.exe -m rigid_coupling --scene buoyancy_pool --arch cuda --single --rigid-density 2 --duration 4 --sample-every 100
.\.venv\Scripts\python.exe -m rigid_coupling --scene buoyancy_pool --arch cuda --single --dt 0.001 --duration 3 --sample-every 200
```

10 秒对比结果目录为 `results/rigid_coupling/20261025-170839-761000+0800_buoyancy_pool/`。两组保存的初始粒子 NPZ 逐字段完全相同。池底高度为 0.09375，初始刚体质心高度为 0.62。

| 10 秒时的指标 | 单向 | 双向 |
| --- | ---: | ---: |
| 刚体质心高度 | 0.183750 | 0.614970 |
| 刚体最低表面距池底 | 约 0 | 0.411433 |
| 刚体竖直速度 | 约 0 | −0.001065 |
| 粒子超出池壁距离 | 0 | 0 |
| 水粒子进入刚体内部数量（深度 > 1e−5） | 0 | 0 |

含初态、每 0.4 秒记录一次的轨迹中，双向组最大刚体形状误差为 6.05e−8，最大水粒子表面穿透深度为 3.87e−7；两组记录的粒子超界距离均为 0。这些值对应采样时刻；每个物理步另有有限值和网格索引范围检查。

密度比 2 的双向刚体在 4 秒时降至质心高度 0.183790、最低表面到达池底，结果在 `20261025-171052-066590+0800_buoyancy_pool/`。它仍有接触抖动，不能据此认定静止接触已收敛。轻刚体持续由水支撑且重刚体下沉，支持当前场景具有定性的浮力响应。实现没有按水位指定的向上力：反馈来自 PBMPM 体积投影、刚体占据体积和表面接触的反作用。

步长减半后，轻刚体在 3 秒时仍浮起，质心高度为 0.646486；原步长在 2.8–3.2 秒约为 0.6264。结果在 `20261025-171152-771029+0800_buoyancy_pool/`。当前水面高度和浮动姿态仍受步长、采样和迭代影响，尚未验证阿基米德排水量的定量精度。此版本适合单双向反馈的对照和方法验证。

水池两组均采用几何刚体与池壁接触，刚体 G2P 排除直接的网格边界裁剪；流体保留网格边界并在积分时限制于池内。刚体表面接触使用预测 OBB、有效质量、等量反向冲量与力矩。接触为迭代近似投影，不保证任意步长和任意多体情形下严格无穿透。

## 偏心流体冲击

运行命令：

```powershell
.\.venv\Scripts\python.exe -m rigid_coupling --scene eccentric_impact --suite --gravity 0
```

参数为网格 32³、每块 6³ 个粒子、步长 0.002、每步 5 次迭代、物理时长 0.1 秒（50 步）。两种模式的初始粒子状态逐字段完全一致；每 5 步记录一次指标，含初态共 11 个采样时刻。

| 0.1 秒时的指标 | 单向反馈 | 双向反馈 |
| --- | ---: | ---: |
| 刚体水平速度 | 0 | 0.466134 |
| 刚体绕 z 轴角速度 | 0 | 1.183054 |
| 流体质量加权平均水平速度 | 0.410987 | 0.717494 |
| 采样时刻最大形状位置误差 | 3.87e-8 | 4.84e-8 |

形状位置误差为粒子位置与 `c + R r` 的最大距离。单向模式的刚体保持静止；双向模式产生平移、转动，并改变流体响应。两种模式的 `run.json` 均为 `completed`，保存的所有浮点状态均有限。

本机结果目录：`results/rigid_coupling/20261025-152939-895919+0800_eccentric_impact/`。其中 `comparison.json` 汇总两种模式，子目录保存参数、源码 SHA-256、CSV 轨迹及初末 NPZ 状态。结果目录按项目原有规则不纳入 Git；上述命令可重新生成。

## 纯刚体离散更新

使用相同网格、采样数、时间步与迭代次数，关闭重力，运行 0.02 秒。初始线速度为 `(0.2, 0, 0.1)`，角速度为 `(0.4, 0.6, 1.2)`。10 步后速度保持在浮点误差范围内，逐步采样的最大形状位置误差为 5.03e-8。

结果目录：`results/rigid_coupling/20261025-152708-514585+0800_pure_rigid/`。

这里验证的是论文当前离散公式的实现：位移采用速度乘步长，姿态采用一阶四元数更新；投影只使用粒子平移位移反馈。当前材料验证场景为流体与刚体，具体实现范围见 `README.md`。
