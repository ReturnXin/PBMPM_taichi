# 鼠标摇晃盒子演示

- `water.gif`：水层上放置 3 个绿色轻质刚体，盒子摇晃时水面产生波浪。
- `soft.gif`：3 个彩色小软体和 3 个绿色小刚体，展示下落、变形、推挤和翻滚。

两份 GIF 使用同一条自动摇晃轨迹，物理时间均为 4 秒。水粒子的显示半径已经缩小。水中刚体使用现有的近似浮力辅助，默认保持漂浮；软体演示没有附加浮力或支撑辅助。

软体接触的默认摩擦系数为 0，盒壁及小刚体接触均不施加切向摩擦。交互默认每帧推进至多 2 个物理步，每步仍进行 5 次迭代，时间步为 0.002 秒，显示上限为 120 FPS。窗口显示实测 FPS 和实际播放倍速，每 0.5 秒更新。实际播放 1x 表示现实经过一秒，仿真也推进一秒。

默认从每帧 1 步提高到 2 步，运动改善仍取决于计算性能。也可在命令中使用 `--substeps 1` 或 `--substeps 4`。物理时间步及材料参数保持一致。

## 手动操作

在 PowerShell 中先进入代码目录，再运行其中一条：

```powershell
Set-Location -LiteralPath 'D:\mine\learningMarkdown\科研知识库\code\PBMPM_taichi'
.\.venv\Scripts\python.exe -m rigid_coupling --scene shake_water --gui --arch cuda
.\.venv\Scripts\python.exe -m rigid_coupling --scene shake_soft --gui --arch cuda
```

当前水场景默认固定盒子，按住鼠标左键并拖动，向所有水粒子施加水平加速度，无需选择或抓取局部粒子。加速度方向取相邻两次鼠标位置的差值，往哪边拖就往哪边施力，然后按物理时间步积分；默认力度再次降低 30%，加速度上限为 15.75。按住不移动或松开时不新增鼠标力，已有惯性继续保留。横向拖动控制左右，纵向拖动控制前后，只施加水平 X/Z 运动，竖直起伏由重力、压力和接触产生；软体场景的左键仍移动、倾斜盒子。两种场景均用线框绘制外盒。右键调整视角时停止鼠标力，`A` 切换自动摇晃及鼠标控制，`Space` 暂停，`R` 复位，`Esc` 退出。打开后直接开始播放。

## 记录

`water_metrics.csv`、`soft_metrics.csv` 保存运动和接触数据，`*_record.json` 保存参数、帧数及源码哈希。`*_final_particles.npz` 和 `*_final_bodies.npz` 保存末态。这里已有的 GIF 使用旧版部分实心墙面绘制；重新录制使用线框，计算中仍是封闭盒子。

这是交互效果演示；当前软体仍使用 PBMPM 弹性求解。水的浮力辅助依据平均水位估算，尚未标定真实材料和波浪载荷。
